---
name: noetloom-bootstrap
description: Create or adopt a project using Noetloom, then implement in the requested workspace.
---

Locate the distribution root containing `BOOTSTRAP.md`, `noetloom/`, and `templates/`:
from this skill's directory, go up three directories in the reference repository or
two in a portable plugin.
Read `BOOTSTRAP.md` there. It owns generation and workspace selection. Run its
bootstrap command from that distribution root, using the user's requested target.
Read the generated project's AGENTS.md before work there.
Keep applications outside the reference kit unless maintaining an explicit example.
