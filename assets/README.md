# Shared logo

`logo.svg` reuses ShardLoom's current faceted diamond symbol for Noetloom
at the owner's request. It is Apache-2.0 material, outside the MIT-0 starter-template
scope. Copyright 2026 Dylan Justin Heinrich; see the repository LICENSE and NOTICE.

Source: [`website-public/assets/logo/shardloom-mark.svg`](https://github.com/depsilon/shardloom/blob/42eb2a033b9bc07859a58e1f8edb9c3f1a242302/website-public/assets/logo/shardloom-mark.svg),
verified against the published GitHub main revision on October 4, 2026.
Original SHA-256: `6107292413cb8e2f4d587c8425542d4724cb8b079fd23246bbcdd049c1377d54`.

The only modification is adding numeric `width="128" height="128"` to the root SVG.
Geometry, colors, and the 40 × 40 viewBox are unchanged. Explicit 128 × 128 dimensions
meet the plugin listing's minimum size. The builder copies this same file to
`assets/icon.svg`; there is no separately maintained redraw.
